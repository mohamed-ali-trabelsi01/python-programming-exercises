# Python Programming Exercises & Algorithms

A collection of Python programming exercises focused on programming fundamentals, algorithms, problem-solving, and small command-line applications.

## About

This repository contains exercises completed while practicing Python and algorithmic thinking.  
The code includes examples of searching, sorting, string processing, mathematical algorithms, matrix operations, validation tasks, and small interactive programs.

## Topics Covered

- Python fundamentals
- User input and output
- String manipulation
- Linear and binary search
- Recursive algorithms
- Sorting algorithms
- List and interval manipulation
- Matrix row operations
- Sudoku validation
- Number and check-digit algorithms
- Small command-line programs

## Exercises

### Searching & Algorithms
- `linear.py` — Linear search
- `binary.py` — Binary search
- `run_back.py` — Recursive binary search
- `insert.py` — Search insert position
- `nadel.py` — Substring search
- `rotate.py` — List rotation
- `intervals.py` — Merge overlapping intervals
- `merge.py` — Merge two sorted lists

### Sorting
- `bubble.py` — Bubble sort
- `bogo.py` — Bogo sort

### Mathematics & Validation
- `palindrom.py` — Palindrome check
- `divide.py` — Integer division without using the normal division operation
- `neuner.py` — Repeated digit sum
- `iban.py` — German IBAN check-digit calculation
- `luhn.py` — Luhn/check-digit validation
- `einstein.py` — Energy calculation using E = mc²

### Matrices & Sudoku
- `zeilen.py` — Matrix row operations
- `einsen.py` — Matrix row operations
- `stufen.py` — Matrix row operations / row-echelon practice
- `sudoku.py` — Sudoku row and column validation
- `sudoku2.py` — Sudoku 3×3 block validation

### Strings & Small CLI Programs
- `playback.py` — Replaces spaces in user input
- `faces.py` — Converts text emoticons to emoji
- `strings.py` — Basic string comparison
- `extensions.py` — Determines MIME type from a file extension
- `interpreter.py` — Simple arithmetic interpreter
- `tip.py` — Tip calculator
- `emojize.py` — Converts emoji aliases to emoji
- `zahlenjagd.py` — Number guessing game

## Requirements

Most exercises use only the Python standard library.

For `emojize.py`, install the `emoji` package:

```bash
pip install -r requirements.txt
```

## Running an Exercise

Clone the repository and run any exercise with Python 3.

For example:

```bash
python binary.py
```

or:

```bash
python zahlenjagd.py
```
